# Snapnote

A phone-first camera for the thing you will not remember later. Snap a photo, dictate or type why it matters, and file it in a folder.

Photos and notes stay in the browser on that device.

## Use it

- Tap the shutter to take a photo, or pick one from your library.
- Dictate the note, or type it.
- Save it into a folder. Rename or delete folders, and delete individual photos.

## Develop

```bash
npm install
npm run dev
```
